# Purrfect Care - Cat Website Project

A multi-page Web Development project for **Purrfect Care**, a cat care service business. This project covers the full development lifecycle, starting from the Part 1 HTML structure and assessment, and moving into Part 2 CSS styling and responsive layout design.

---

## Overview

This repository contains the full source code for the **Purrfect Care** website. 

* **Part 1 (HTML Foundation):** Focused on semantic HTML5 structure, form handling, inter-page navigation, and core project management / RFP documentation. **Achieved Score: 83/100.**
* **Part 2 (CSS Styling):** Focused on visual design, CSS styling, layout structure, color schemes, and responsive web design in Visual Studio Code.

---

## Site Navigation & Pages

The project consists of 5 interconnected pages linked across all site navigation bars:

* **`index.html`** — Main landing page featuring business highlights, key services, and a welcome section.
* **`about.html`** — Background information on the company, including history, mission, and core values.
* **`services.html`** — Complete service directory (Grooming, Sitting, Health Checkup, Kitten Socialization) with pricing and a service booking form.
* **`gallery.html`** — Image gallery showcasing client cats across various service categories.
* **`contact.html`** — Business contact details and interactive customer inquiry form.

## Part 2: CSS Implementation Plan

Now moving into Part 2, the plain HTML files are being enhanced with modern CSS stylesheet design.

### Planned CSS Features
* **External Stylesheet (`styles.css`):** Centralized styling linked across all 5 HTML documents.
* **Color Palette:** Warm, cat-friendly aesthetic featuring soft pinks, warm grays, and dark charcoal typography.
* **Flexbox & Grid Layouts:** Clean card alignment for the services page and a multi-column layout for the photo gallery.
* **Form Styling:** Modern styling for input fields, labels, fieldsets, and submit buttons.
